# 目录双语 · Bilingual Outline

为 Zotero 的 PDF 原有目录添加中文对照，保留英文、层级、折叠与点击定位。

面向 **Windows / Zotero 10.0.1–10.0.x / 个人文库**，包含独立 PDF。只处理已有目录；不生成目录、不做 OCR，不扫描文库自动翻译。

## 安装

从 [最新正式版本](https://github.com/lllaterOn/zotero-bilingual-outline/releases/latest) 下载 XPI，在 Zotero 插件管理器中选择“从文件安装插件”。

首次从 0.1.x 测试版升级需手动安装正式 XPI；插件 ID 和缓存格式保持不变，已有译文与本机密钥继续使用。正式版通过本仓库更新清单提供后续更新。

## 使用

1. 打开 Zotero 设置 → 目录双语，配置 DeepSeek 官方 API Key。预设模型为 `deepseek-flash`，费用由服务商按账户计收。
2. 打开已有目录的 PDF，在左侧目录栏顶部点击翻译图标。仅发送论文标题和目录，不上传 PDF 正文。
3. 三个图标依次是翻译、中英显示切换、全部展开／收起。悬停查看操作名称；没有子层级时展开按钮不可用。
4. 已有译文自动显示；右键中文标题可以修订。整份重新翻译成功后覆盖旧译文（包括修订），失败保留旧译文。

“已配置”只表示密钥已保存，并不表示已验证服务可用。密钥仅保存在本机；另一台电脑只阅读已有译文时无需密钥。

## 多机同步

每台电脑先完成 Zotero 自带同步，再在本插件设置中连接同步笔记。设置同步与译文同步分别开关；密钥和同步开关不上传。

插件共用系列软件条目 `Personal zotero addons`，自己的设置与译文分别存入专属笔记；译文接近单笔记容量时自动追加编号笔记。插件不依赖 Focus Columns，不创建标签。

插件协调本地笔记，实际云端上传下载由 Zotero 完成。“笔记已连接”不代表云端已同步。不同 PDF 的并发修改合并保留；同一 PDF 的冲突通过阅读器冲突按钮选择一整份版本。设置冲突在设置页出现的“解决设置冲突”按钮中处理。

## 数据维护

“清理失效译文”仅清理 PDF 条目已永久删除的记录，先预览并保存最近一次本机备份。回收站条目、暂未下载或文件不可用均保留。可通过“恢复最近清理”恢复这份备份。

本机数据位于 Zotero 数据目录下 `bilingual-outline/state.json`，最近清理备份为 `cleanup-backup.json`。不要直接编辑插件数据笔记；中文修订通过阅读器完成。卸载插件不会删除 PDF、共享父条目或译文笔记。
