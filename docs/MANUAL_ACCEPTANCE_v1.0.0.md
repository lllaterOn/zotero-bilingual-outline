# v1.0.0 验收记录

日期：2026-09-12。

## 已有依据

维护者在实际 Zotero 使用和多轮反馈修复后，明确确认当前版本功能完整、无误，可作为正式 v1 发布，并同意发布 v1.0.0。
本次从 0.1.9 保留运行逻辑、插件 ID、缓存与笔记格式，仅整理仓库及正式版本、更新地址与发布流程。

这是一项维护者总体确认，不伪造逐项测试结果。当前记录未附独立的双机并发、清理恢复或 Zotero 10.0.1 每项测试日志。
自动化模拟测试和包校验由本地与 GitHub Actions 分别执行，结果查看发布对应提交的工作流。

## 后续版本人工检查清单

- 有目录 PDF：手动翻译、中文修订、重开缓存、原目录跳转。
- 中英切换、嵌套目录展开／收起、切换 PDF 和重启。
- 请求失败后保留原译文，忙碌状态解除；成功重译覆盖全部。
- 设置密钥留空、取消、更换、清除，两个同步开关独立。
- A/B 两机缓存同步；不同 PDF 离线修改均保留；同一 PDF 冲突整份选择后收敛。
- 回收站或不可用文件不清理；永久删除后预览、备份、清理、跨机不复活、恢复最近清理。
- 从上一正式版升级，已有密钥与数据继续可用。
