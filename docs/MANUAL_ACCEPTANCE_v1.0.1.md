# v1.0.1 验收记录

日期：2026-09-25。

## 变更范围

本版本只修改插件管理器显示的名称和描述。插件名称统一为 `Zotero Bilingual Outline`，描述为“为 PDF 目录添加中文对照，支持手动翻译、修订与笔记同步。”插件 ID、偏好设置、同步数据格式与运行逻辑均未修改。

## 自动检查

- 本地 `npm run verify` 已通过：类型检查、44 项模拟测试、仓库卫生、构建产物和 XPI 清单均通过；本地候选 XPI 的 SHA256 为 `cf32f03284ef9628200b5005f1133dfc85c44e949729422c61b5d9b3ec24d5b2`。
- GitHub Actions 对发布标签重新执行相同验证，并生成 Draft Release 的 XPI 与 SHA256 摘要。
- 发布前下载 Draft Release 的原始资产，核对摘要、版本和清单元数据。

这些检查验证源码、构建和发布资产的一致性，不等同于 Zotero 实机验收。

## Zotero 实机验收

本版本发布前未启动或控制 Zotero，也未安装候选 XPI。维护者本次明确授权先正式发布，再通过 Zotero 自动更新接收并验收该版本。因此，发布前不记录任何实机检查为已通过。

自动更新后应确认：

- 插件管理器显示名称 `Zotero Bilingual Outline`。
- 插件管理器显示中文描述“为 PDF 目录添加中文对照，支持手动翻译、修订与笔记同步。”
- 版本显示为 `1.0.1`，插件保持启用，原有设置与译文数据可继续使用。
